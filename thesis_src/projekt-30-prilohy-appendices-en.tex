\chapter{Structure of the Submitted Archive}

The submitted archive contains the following files and folders. More details about the project structure, as well as an application manual and a guide for setting up, running, and exporting the project within the Godot Engine, can be found in \texttt{README.md}.

\begin{itemize}
    \item \texttt{thesis\_src/} -- contains source files of the \LaTeX~thesis project.
    \item \texttt{demo\_src/} -- contains the source code of the demo implementation.
    \item \texttt{build/} -- contains demo executable binaries for multiple platforms.
    \item \texttt{extra/} -- contains files submitted in the Excel@FIT conference (poster and abstract).
    \item \texttt{README.md} -- contains details about the submitted archive, project structure, application manual, and guide for setting up, running, and exporting the project within the Godot Engine.
    \item \texttt{video.mp4} -- demonstration video of the generator and demo capabilities.
    \item \texttt{thesis.pdf} -- copy of this thesis in the PDF format.
\end{itemize}
